# brand — 版元ロゴの置き場所

ここに `amayadori-logo.png`（あまやどり出版のロゴ。ミント地にアーチ、蓮の葉の下のカエル）を
置くと、入口ヘッダーの BrandLogo（src/components/FrogMark.tsx）が自動でこれを表示する。
無い間は線画の FrogBadge が代わりに出る。

- ファイル名は **amayadori-logo.png** 固定（コードがこの名前を見る）
- 差し替えるときも同じ名前で上書きすればよい

## 本ちゃか(スタジオのロゴ。2026-10-07)

- `honchaka-mark.svg` … 絵だけ(4冊の背表紙と、金茶の本からのぞくカエル)。題字・トップの見出しは、これと HTML の字で組む(`StudioLogo`)
- `honchaka-logo.svg` … 絵+「本ちゃか」+「ひっちゃか本づくりスタジオ」。字も図形にしてあるので、書体の無い所(ほかのサイト・資料)に貼れる。明るい地向け
- `honchaka-logo-dark.svg` … 同じ形の暗い地向け(字が明るく、絵に生成りの縁)
- タブのアイコンは `../favicon.svg`(カエルのところだけ切り出し)
- 元は画像生成の手描きの絵。元の絵と比べた4案は、非公開の資料フォルダの `資料/本ちゃかロゴ_20261007/`
